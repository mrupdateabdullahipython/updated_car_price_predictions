# 🚗 Ferrari Style Car Price Prediction App

A world-class Machine Learning web application that predicts car prices in Nigeria using Linear Regression.

## 🔥 Features

- Predict car prices instantly
- Ferrari-inspired premium UI
- Beautiful background car design
- Smart machine learning model
- Built with Streamlit

## 📊 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
